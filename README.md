<details>
<summary><b>⚙️ Distributed Key-Value Store — Go · Raft · gRPC</b></summary>
<br/>

```
Architecture  : Multi-node Raft · Leader Election · Log Replication · Fault Injection
Performance   : 10,000–15,000+ ops/sec across 5 nodes under chaos conditions
Consistency   : Strong consistency via Raft — no dirty reads, no split-brain scenarios
Transport     : gRPC with zero-copy serialization for minimal inter-node overhead
Resilience    : Automatic leader failover · partition recovery · membership changes
```

**Why it matters:** Most engineers use distributed databases. I understand how they work at the protocol level — log entries, commit indices, term numbers, quorum decisions. This project proves systems-level thinking, not just framework fluency.

</details>

<details>
<summary><b>🧠 NeuralStream — Production LLM Inference & RAG Platform</b></summary>
<br/>

```
Daily Traffic  : 10,000+ requests served

Eval           : RAGAS-based evaluation pipeline for continuous quality monitoring
```

**Why it matters:** Building a RAG demo takes an afternoon. Building RAG that's fast, cheap, accurate, and monitored in production is a different engineering problem entirely. I've solved it.
